# 短剧标题生成规范 v4.1（项目实战版 · 2026-10-28）

> 本文件是标题生成的**唯一执行标准**（原 `assets/title_prompts/v4_spec.md`）。与 SKILL.md 冲突时以本文件为准。
> 来源：v3 规范在「赶山救下小狐狸，所有猛兽都听我的」一剧的实战迭代。
> 本版新增：素材边界纪律、12 条产出结构（3×4）、钩子手法库、爽点递进链、打脸四式、版4 机制族。
> v4.1 变更：新增版4 机制版与八族技法池，产出由 9 条扩为 12 条，门禁改为 12 条编号依次选。
> v3 原始规范保留在同目录历史版本中，本版为执行标准。

## 0. v3 → v4 修正的实战教训（必读）

| 教训 | 错误表现 | v4 规则 |
|------|---------|---------|
| **编造剧情**（最严重） | 简介只写「遭義兄背叛」，却脑补出踹下崖/进大牢/铜铃被夺/爹气死 | 简介没写的事件一律不存在，见 §2 黑名单 |
| **字数不足** | 25-30 字的"一句话摘要"，钩子爽点没塞满 | 每条 60-80 字，低于 50 字直接不合格重写 |
| **漏方案层** | 只出 3 条（三版本各一），没出 12 条 | 必须三方案 × 四版本 = 12 条，见 §1 |
| **打脸泛化** | 「腸子悔青」「跪地求饒」无画面 | 用打脸四式，见 §5 |
| **版本趋同** | S1-版2 与 S3-版2 写成同一条路子 | 方案差异化硬约束，见 §1.3 |

## 1. 产出结构：3 方案 × 4 版本 = 12 条

### 1.1 方案层（怎么讲）

| 方案 | 策略 | 系列特征 |
|------|------|---------|
| **S1 taiyo** | 身份反差 · 数字冲击 | 重「数字与资产」：現錢堆山、一車車拉回、三車大洋 |
| **S2 coppie** | 情感驱动 · 冲突对比 | 重「恩怨情感对撞」：背叛之冷 vs 报恩之暖、那聲「兄弟」 |
| **S3 viral** | 好奇缺口 · 社会认同 | 重「群体反应与身份反转」：全县笑話 → 全村仰望 |

### 1.2 版本层（讲什么）

| 版本 | 定义 | 结构 |
|------|------|------|
| **版1 爽文①** | 先抑后扬 · 抓马现场打脸线 | 踩慘開場 → 誰知轉折 → 異能畫面 → 財富爆發 → 當場打臉 → 誇張收尾 |
| **版2 爽文②** | 先抑后扬 · 前世回溯雪耻线 | 曾經慘狀回溯 → 如今開掛 → 積累翻盤 → 「連本帶利討回一切」收尾 |
| **版3 傳奇版** | 专属狠反问（两范式） | 誅心戳背叛款 / 霸氣守山款，見 §1.4 |
| **版4 機制版** | 技法池驱动的第四写法（**不绑构图**） | 从 §1.5 八族中取 1 族 + 至多 1 个次机制，结尾仍走打脸四式 |

版1 与版2 拉开差异：版1 重「現場即時打臉」，版2 重「積累回溯算總帳」，不重复同一镜头。

版4 与前三版的差异在**讲法来源**：版1/2/3 是叙事结构（现场/回溯/反问），版4 是机制（数字反差、结局倒叙、悬念缺口等）。版4 不绑固定构图，被选入任一封面位时沿用该封面位的构图。

### 1.3 方案差异化硬约束

同版本下三个方案必须走明显不同的路线。检查法：把 12 条标题打乱，只看「爽点类型 / 机制族」能否分辨出属于哪个方案、哪一版——分不出即重写。

### 1.4 版3 两范式（反问必须绑定本剧专属剧情）

- **誅心戳背叛款**：紧扣背叛/构陷细节，戳破「兄弟/情义」伪装，直击道德痛点。
- **霸氣守山款**：以主角地位/地盘/实力为核心，踩对方「不配入门/分一杯羹」。

### 1.5 版4 机制族（八族技法池）

40 种泛新媒体技法筛并为 8 族，只为版4 服务。三格必须取**不同族**，且不得与同版本 S1/S2/S3 已用的讲法重复。族内可叠 1 个次机制，主族只能 1 个。

| 族 | 核心机制 | 短剧化模板 | 禁用 / 注意 |
| --- | --- | --- | --- |
| M1 数字资产反差 | 极小投入 ↔ 极大产出 | 一枚銅鈴，換來萬獸聽令、參王滿車 | 不得写简介外的金额、数量、时间 |
| M2 关键物件聚焦 | 单一物件承接全剧 | 所有人都在找的那枚銅鈴，只認他一個主人 | 物件必须是简介明写的 |
| M3 结局倒叙 | 先讲如今，再揭当年 | 如今他站在禁地入口……很少有人記得當年 | 不得倒叙出简介外结局 |
| M4 身份体面反差 | 明面体面 ↔ 暗地狼狈 | 口口聲聲喊兄弟的那個人，如今連頭都不敢抬 | 不得编造对方现状与行为 |
| M5 价值情绪反转 | 本該…卻… | 本該他跪著求人，如今換貴人排隊等他點頭 | 不得编造具体场面人物 |
| M6 群体社会反应 | 众人态度 180 度转向 | 當年笑他的人，如今全仰望 | 群体反应属白名单，可放大不可新造事件 |
| M7 悬念信息缺口 | 只给一半答案 | 他搖鈴那一刻，整座山都安靜了—— | 缺口必须在简介内可兑现 |
| M8 处境痛点点名 | 直呼受众处境 | 埋頭趕山十年，不如一枚銅鈴 | 不得引入简介外的身份设定 |

**整族剔除**（不做改造）：清单体、步骤体、避坑体、省钱体、私藏体、代际说教、两难选择题、禁忌窥探、热点前置、地域标签。

## 2. 素材边界（每条不可破，最高优先级纪律）

### 2.1 白名单：允许夸张的维度

| 维度 | 允许的放大 | 依据 |
|------|-----------|------|
| 异能画面 | 號令萬獸 → 猛虎開道、黑熊尋參、狼群護航 | 「异能用直白画面表述」 |
| 财富堆砌 | 現錢堆成山、一車車拉回、賣爆省城/全縣 | 总则示例短语 |
| 贵人态度 | 踏破門檻、爭相交好、登門求見、當場稱兄道弟 | 「结识省城贵人」的放大 |
| 社会反应 | 全村仰望、眼都看直了、當他是個笑話 | 「震慑群小」的群体反应 |
| 地位碾压 | 大山之王的領地、連仰望的資格都沒有 | 「一代大山之王」的放大 |

### 2.2 黑名单：禁止编造（实战翻车记录）

| 禁止项 | 翻车案例 |
|--------|---------|
| 背叛的具体方式 | ❌「被踹下懸崖搶走千年參」——简介只写「遭義兄背叛」 |
| 牢狱之灾 | ❌「送進大牢、作偽證」——简介只写「栽贓陷害」 |
| 亲人死亡方式 | ❌「老爹活活氣死在參田」——简介只写「父親遺願」 |
| 具体恩怨往事 | ❌「斷腿那年背他下山」「從狼群裡背出來」——凭空捏造 |
| 反派具体下场 | ❌「義兄跪縣衙吐三千大洋」——反派的行为不能编 |

**判别法**：主角获得的财富/地位/贵人态度可以夸张放大；任何**角色的新增行为**（背叛方式、下场、死因）都不许编。

### 2.3 关系强化表述（可用）

「拿義兄當親哥」「口口聲聲喊兄弟」属于对「義兄」二字的关系强化，不是新增剧情事件，允许使用。

## 3. 钩子手法库（开头 3 秒）

| 手法 | 示例 |
|------|------|
| **情感反差** | 他拿義兄當親哥，義兄卻反手背叛—— |
| **身份歧视反问** | 一個趕山的也配號令萬獸？ |
| **对仗短句** | 口口聲聲喊兄弟，轉頭就背叛—— |
| **好奇缺口** | 誰能想到，遭義兄背叛的趕山漢，轉身得狐女報恩—— |
| **群体嘲笑开场** | 遭義兄背叛那陣子，全縣都當他是個笑話—— |

禁止平铺开场（「曾遭義兄背叛的他」「義兄背叛他的那天」属不合格开场）。

## 4. 爽点递进链（每条压满 5-6 个爆点）

```
绝境/背叛 → 报恩道具(铜铃) → 万兽异能画面 → 奇珍/参王出土
→ 财富爆发(现钱/大车) → 贵人登门 → 地位碾压收尾
```

递进方向只能向上（雪球越滚越大），不许平行罗列同级爽点。

## 5. 打脸四式（结尾具象化）

| 式 | 用法 | 示例 |
|----|------|------|
| **资产对比式** | 我方被抢购 ↔ 对方无人问津 | 省城貴人抬現錢堆成山上門搶購，背叛他的人悔斷了腸 |
| **资格剥夺式** | 连仰望都不配 | 背叛他的人只能仰望這位大山之王 |
| **领地准入式** | 一步都不许进 | 如今也配踏進這座大山之王的領地一步？ |
| **面子诛心式** | 脸往哪搁 | 當年背叛他的義兄聽了，臉還掛得住嗎？ |

禁止泛化打脸（「腸子悔青」「跪地求饒」「看傻了」单独使用无画面时）。

## 6. 每条质检清单（出稿前逐条过）

- [ ] 字数 60-80（版3 反问句允许 55-70；版4 同 60-80）
- [ ] 全繁體，零简体
- [ ] 第三人称「他」；版3 反问句视角仍保持第三人称叙事框架
- [ ] 无主角本名
- [ ] 每个素材在简介有出处（对照 §2.1 白名单）
- [ ] 爆点 ≥ 5 个，呈递进链
- [ ] 开头用 §3 钩子手法之一，禁止平铺
- [ ] 结尾用 §5 打脸四式之一
- [ ] 同版本跨方案差异可辨（§1.3）
- [ ] 版4 额外：标注所用机制族（M1—M8），三格族不重复
- [ ] 版4 额外：遮住标题只看内容，能说出「这条靠的是哪个族」，且与同版本 S1/S2/S3 讲法不同
- [ ] 无 A 层绝对化用语（最、唯一、第一、非他莫屬 等），见 `platform-rules.md`

## 7. 实战标杆（赶山剧 · 已验证通过）

### S1 taiyo

**版1**：他拿義兄當親哥，義兄卻反手背叛——誰知狐女報恩送來通靈銅鈴，搖一搖猛虎開道、黑熊尋黑熊尋參，絕品參王一個接一個出土，省城貴人抬現錢堆成山上門搶購，背叛他的人悔斷了腸！

**版2**：當年遭義兄背叛，他連口氣都沒處發——如今通靈銅鈴在手，萬獸聽令尋遍奇珍，絕品參王一車車拉回賣爆省城，貴人爭相登門，趕山隊重新聚攏，背叛他的人只能仰望這位大山之王！

**版3**：銅鈴一搖萬獸聽令、奇珍滿倉、參王出土，連省城貴人都要登門求見——當年背叛他的義兄，如今也配踏進這座大山之王的領地一步？

### S2 coppie

**版1**：義兄背叛他那一刻，全山只有狐女記得他的恩——報恩的通靈銅鈴一搖，萬獸出山替他撐腰，絕品參王起出土賣爆省城，栽贓陷害他的人被猛獸圍得腿軟，省城貴人當場跟他稱兄道弟！

**版2**：義兄背叛他時毫不手軟，狐女卻記著他的恩情——報恩的通靈銅鈴一搖，萬獸聽令奇珍滿倉，絕品參王賣爆省城，貴人踏破門檻，背叛他的人這才知道，什麼叫連本帶利討回一切！

**版3**：口口聲聲喊兄弟，轉頭就背叛——如今他搖響銅鈴萬獸出山，成了整座大山的主人，當年那聲「兄弟」，他記下了，這筆帳連本帶利討回來！

### S3 viral

**版1**：誰能想到，遭義兄背叛的趕山漢，轉身得狐女報恩——一枚通靈銅鈴搖一搖，萬獸出山聽他號令，絕品參王一個個自己冒出土，省城貴人搶著登門，全村人眼都看直了！

**版2**：遭義兄背叛那陣子，全縣都當他是個笑話——誰知狐女報恩的通靈銅鈴一響，萬獸聽令、奇珍出土，絕品參王一車車拉回賣爆省城，當年笑他的人，如今全村仰望這位大山之王！

**版3**：一個趕山的也配號令萬獸？可省城貴人登門求見、絕品參王一車車拉回，大山之王的名號響徹山野——當年背叛他的義兄聽了，臉還掛得住嗎？

## 8. 生成流程（Agent 执行序）

1. **Step 0 素材圈定**：通读简介，列出可用元素清单（人物/道具/能力/事件/地位）
2. **Step 1 白名单对照**：确认每个夸张点都落在 §2.1 五个维度内
3. **Step 2 按 12 格矩阵生成**：先定每格的钩子手法和打脸式；版4 三格先定机制族（M1—M8 不重复），再填充内容
4. **Step 3 逐条过 §6 质检清单**
5. **Step 4 差异化检查**：§1.3 分辨法，12 条一起打乱
6. 输出：12 条标题，编号 T1—T12，每条标注（方案×版本·钩子手法或机制族·打脸式·字数·七维总分）
7. **Step 5 用户选择门禁（强制）**：12 条平铺呈现后**停下**。用户依次为封面1 / 封面2 / 封面3 各选 1 条，每次回复一个编号（T 编号），也可一次给出三个编号；用户也可完全绕过 12 条、自主提供 3 条标题。**Agent 不得代选、不得自动进入阶段 2**。跨版本选择合法：构图由封面位决定，版4 被选中时沿用该封面位构图。
