# 短剧封面生成规范（v2 · 2026-10-27 用户版）

## 一、硬约束（每条都不可破）

1. **彻底无文字**：封面不出现任何汉字、数字、字母、符号、印章、木牌刻字、门上囍字、底部书法标题——参考图里的金红书法全部由 image_edit 抹掉。

2. **无武器**：不出现枪、弓、箭囊、刀、斧、棍棒、猎叉。参考图里男主手里的弓箭/斧子/木棍一律移除；文案里提到"猎枪""一把斧"只做剧情理解，不进画面。

3. **无血腥**：不出现伤口、血迹、猎物尸体、猎杀场景；动物只做活着的守望/护卫/随行，不扑咬不攻击不咆哮（熊虎也要改成安静蹲伏）。

4. **无儿童**：不出现小孩、婴儿、虎头帽小孩、女童。剧情里"两妹""妻女"只做背景叙事，不进画面。

5. **人物为成年东亚面孔**。

6. **尺寸严格**：横版 2848×1600，竖版 1080×1920；模型原始输出约 2732×1535 / 1536×2730，必须用 PIL Image.LANCZOS 缩放到精确像素。

7. **动物完整性（P0）**：画面出现动物必须完整呈现，不得裁切/遮挡/截断头、四肢、尾，不得只露局部；主体动物必须完整落在画面内且外形可辨识。判定基准是**扣掉标题占位后的安全画面区**——竖版顶部标题区不能切断动物身体。这条横版、竖版都适用。

## 二、三版构图规范（按剧情爆点反推，不套模板）

每组 3 横版 + 1 竖版（组数由门禁分组选择决定，见 §二.5），三版必须从当部剧的剧情钩子（系统/兽潮/悔婚/商战/复仇/宝光/点化等）反推独特视觉机制，禁止固定模板：

### 爽文版①（爆点拉满）
低角度仰拍气场全开 + 金色系统光环/宝光 + 猛兽群环绕 + 致富元素堆成山（现钱、山货、毛皮、人参、一车车原木、猎物），对应"谁知转折/打脸/逆袭"。

### 爽文版②（先抑后扬雪耻）
冷暖对比构图——左侧冷青暗调里前世黑影（背叛者/黑煤窑/破屋/看笑话村民），右侧暖金明亮处今生猛兽环绕致富堆满，对应"前世回溯/连本带利讨回"。

### 传奇版（最狠档反问）
固定守护挡身方向——男主侧身护在女主/家人身前、半侧身警惕回头看向侧后方，两张脸被一道暖金色曙光照亮，背后冷青黑暗雾影中浮现模糊黑影（背刺他/栽赃他/看他笑话的人），周围猛兽在雾中若隐若现。营造"身处黑暗但曙光马上到来"。

### 竖版
男主胸像居中 + 女主/猛兽群在侧后，逆光轮廓，适合竖屏投流。

### 二.5 多组封面（各组独立标题 · 同标题视觉 A/B 测试）

每部剧**每组固定 4 张**（3 横 + 1 竖）；组数由门禁分组选择表达式决定（`title-spec.md` §9.6），两组 8 张、三组 12 张，依此类推。

- **标题按组独立**：每组封面使用**本组选中的 3 条标题**（第二组必须用第二组标题，不再默认与 A 组同标题）；构图方向由封面位决定，两组可同构图、也可按剧情再选方向。
- **同标题特例**：跨组选中相同 3 条标题时，后续组走「同标题 + 视觉加码」的 A/B 测试——只提升视觉冲击，不换事实。后续组至少 2 处加码，五类中至少覆盖 3 类：
  1. 光效加码：金光升级多道光柱、地面反光或金色雾；
  2. 规模加码：财宝堆更高、车货列延伸、群体剪影围合；
  3. 压迫加码：镜头更近更仰、前景遮挡、主角占比放大；
  4. 姿态加码：猛兽更贴近守护、头微俯、视线朝前；
  5. 天地比例：主角与财宝占画面约 2/3，天留约 1/3。
- 禁止为制造差异新增剧情事实；受伤血迹、武器、小孩、文字元素始终按第一节硬约束剔除。
- **落盘与登记**：A 组用基础契约名；B 组落 `04_covers/b_group/cover_01_hit_B.png` / `cover_02_contrast_B.png` / `cover_03_guard_B.png` / `cover_04_vertical_B.png`。manifest 记 `group`、`variant_of` 与源图 sha256；文件名容错与账号组识别见 `handoff-contract.md` §4 末条。

## 三、身份锚点与技术流程

1. 每张参考图先在画布 `/user-anchors/` 登记锚点（design-cli +create）。
2. 以参考图 URL 为身份锚点，image_edit 每组出 4 张（3 横版 + 1 竖版），每批 2 个 request、分两批执行。
3. 保留参考图核心身份（男主服装/女主造型/猛兽种类/环境），只改构图、光影、致富元素、黑影对比。
4. 下载后 PIL LANCZOS 缩放到精确尺寸 → FileBatchUpload 上传 → design-cli +create 写入画布（带 source_ids 血缘）→ RichMediaCard 分组交付。

## 四、质量门禁

- **P0 否决项｜动物不完整**：画面出现动物但被裁切、遮挡或截断头/四肢/尾，或只露局部、外形不可辨识 → **整张作废重出，不进入评分**。判定基准是扣掉标题占位后的安全画面区（竖版顶部标题区不能切断动物身体），横版、竖版同标准。出图后需人工/VLM 复核，不引入检测模型。
- 生成后逐张检查：有无残留文字、有无武器、有无儿童、有无血腥、猛兽是否安静守望、动物是否完整。
- 尺寸必须精确到像素。
- 三版构图必须明显不同，不能三张都是"男主站中间金光"。
