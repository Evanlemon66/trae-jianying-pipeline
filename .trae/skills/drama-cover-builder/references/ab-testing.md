# A/B 测试设计（预留，当前未启用）

> **状态：未启用。**
> Stage 1 现阶段只做「比稿 + 评分推荐」，真实 A/B 需要发布/投放数据支撑，等有需求时按本文开启。
> 本文所有平台数字均为建议值或待核实项，不得当作平台官方规则引用。

## 一、先分清三种「选标题」

| 机制 | 依据 | 产出 | 是否 A/B |
| --- | --- | --- | --- |
| 比稿 | 用户主观选择 | 3 条封面标题 | 否 |
| 评分推荐 | 七维评分（`scorecard.md`） | 标注推荐项 | 否 |
| 真实 A/B | 发布后的真实曝光与点击 | 可复用结论 | 是 |

三者不可互相冒充：评分高不等于 A/B 胜出，A/B 结论也不能反过来当"标题写得对不对"的唯一标准。

## 二、A/B 单元与单变量原则

- **单元** = 同一素材（同一集/同一剧）的一套「封面图 + 平台填写标题」；
- 封面按 `cover-spec.md` 为无文字图，因此**标题不在图上**，A/B 变量只能是：
  - 变量 A：构图（封面1 / 封面2 / 封面3 三选二或三选一对比）；
  - 变量 B：标题形态（长叙事标题 vs 短投放标题）——图不动；
- 一次只动一个变量。同时换图和标题，结论无法归因。

## 三、两套常见场景的差异

| 项目 | 长视频发布 A/B | 短剧投放 A/B |
| --- | --- | --- |
| 标题位置 | 平台标题位，字数上限较宽 | 平台文案位，通常更短 |
| 封面 | 可含文字 | 约定为无文字图（见 `cover-spec.md`） |
| 主指标 | 点击率 + 前 30 秒留存 | 封面点击率 + 追剧/付费转化 |
| 干扰因素 | 推荐流波动、发布时间 | 投流计划、创意赛马、出价 |
| 可行方式 | 分次发布或平台原生分桶 | 投流多创意并行或分次发布 |
| 平台能力 | 需核实 | 需核实 |

上表的能力与字数均为**待核实**，启用前先查平台创作者中心/投放后台，核实后写日期。

## 四、指标与观察窗口（建议值，需按实际量校准）

- 主指标：封面点击率（点击 / 曝光）；
- 辅指标：3 秒完播、追剧转化、付费转化；
- 观察窗口：24—72 小时；
- 判定门槛：单条曝光 ≥ 1 万再判（阈值按账号实际流量校准，不跨剧比较）；
- 同一账号、同一时段、同一投放设置下比较，跨剧差异只作参考。

## 五、结果诊断矩阵

| 表现 | 判断 | 动作 |
| --- | --- | --- |
| 高点击、高完播 | 图与题双强 | 保留机制，写入 `failure-cases.md` 台账 |
| 高点击、低完播 | 封面/标题承诺超过正片 | 降承诺，删掉简介撑不住的爽点 |
| 低点击、高完播 | 封面包住弱 | 换构图或换钩子，不动正片 |
| 低点击、低完播 | 剧集或选题错配 | 停止优化封面，换剧/换集 |

## 六、输出模板

```markdown
## A/B 组1（封面位：封面1）
- A：<标题>　封面图：<文件>
- B：<标题>　封面图：<文件>
- 测试变量：构图 / 标题形态（二选一）
- 主指标：封面点击率
- 辅指标：3 秒完播、追剧转化
- 观察窗口：24—72h
- 判定门槛：单条曝光 ≥ 1 万
- 结论：A / B / 不显著
- 可复用机制：<一句话>
```

## 七、落地前提（启用时才需要）

1. 同一集要有**两份可用草稿或两份发布素材**；当前 `batch_runner` 一集只写一份草稿，需要复制草稿再换封面/标题；
2. 封面与标题解耦：构图由封面位决定，标题只提供文字，二者可独立替换；
3. 结论必须回填 `failure-cases.md`，否则下次仍然靠感觉选；
4. 样本不足时写"不显著"，不得用单日波动当结论。

## 八、启用条件

满足任一条再启用本文：

- 已有稳定的投放/发布数据回收渠道；
- 单集曝光能稳定过万，具备可比样本；
- 用户明确要求做发布侧对照实验。
