# Stage 2 出图提示词结构规范 v1（prompt-spec）

> 本文件是「标题 + 构图 → 出图提示词」的唯一拼装标准，渠道无关（豆包/火山/本地共用）。
> 目标：任何宿主照着本文件拼出的提示词，结构与约束完全一致，可直接存入 `03_prompts/`。

## 1. 固定结构（五段，顺序不可换）

```
[1 身份锚点] 参考图说明：图中人物即短剧主角，保持其面部特征、发型、服装与年代感完全一致
[2 构图]     本封面位锁定的构图（见 §2）
[3 画面元素] 从选定标题中提取的可视元素（见 §3 提取规则）
[4 硬约束]   画面中不要出现任何文字、字幕、水印；不要武器；不要儿童；不要血腥；动物必须完整（full body visible, no crop, no occlusion, all limbs and tail inside frame；negative: cropped animal, partial body, cut off limbs, occlusion）
[5 尺寸]     输出尺寸 <宽>×<高> 像素（横版 2848×1600 / 竖版 1080×1920）
```

## 2. 构图段（封面位锁定，与用户选了几版无关）

| 封面位 | 构图 | 构图段模板 |
| --- | --- | --- |
| 封面1 | 爆点仰拍 | 低角度仰拍，主角占据画面主体，情绪爆点瞬间，背景财富元素（现钱、银元、货物）堆叠 |
| 封面2 | 冷暖对比 | 画面左右或前后分冷暖两区：冷区是过去困境（雪夜、破屋、孤独），暖区是如今富足（灯光、收获、人群），主角位于交界 |
| 封面3 | 守护挡身 | 主角侧身挡在家人/产业前方，背后是威胁或轻视他的人群剪影，主角神情坚定 |
| 竖版 | 胸像逆光 | 主角胸像特写，逆光轮廓，背景虚化的财富或山野元素，情绪饱满 |

版4 机制版标题被选入时，沿用所在封面位的构图，不为机制族另设构图。

## 3. 画面元素提取规则

- 只取标题中**名词性可视元素**（野猪、银元、现钱、药材筐、雪夜、荒山、人群、门槛），不取抽象情绪词；
- 每条标题提取 3—5 个元素，按标题中出现顺序排列；
- 元素必须能在简介中找到出处（与 title-spec 素材边界一致）——标题违规时先修标题，不允许提示词悄悄加戏；
- 威胁类元素（狼群、人群剪影）只允许出现在封面3 的"背后"，不作主体。
- **动物完整性约束（P0）**：只要画面出现动物，元素段与硬约束段必须同时给出正向与负向约束——正向 `full body visible, no crop, no occlusion, all limbs and tail inside frame`，负向 `cropped animal, partial body, cut off limbs, occlusion`；主体动物完整落在画面内且外形可辨识，不得只露局部。
- **与竖版标题安全区共存**：判定基准是**扣掉标题占位后的安全画面区**——竖版顶部标题区不得切断动物身体，动物主体必须落在标题占位以下的安全区；横版按标题预留区同理。需要压缩构图时优先缩小动物占比或下移主体，不得裁掉头/四肢/尾。

## 4. 完整示例

```
参考图说明：图中人物即短剧主角，保持其面部特征、发型、服装与年代感完全一致。
构图：低角度仰拍，主角占据画面主体，情绪爆点瞬间，背景财富元素堆叠。
画面元素：三头刚猎倒的野猪、一筐筐珍贵药材、堆成山的现钱与银元、上门抢购的县城客商。
硬约束：画面中不要出现任何文字、字幕、水印；不要武器；不要儿童；不要血腥。
输出尺寸：2848×1600 像素。
```

## 5. 落盘格式

`03_prompts/prompts.json`：

```json
{
  "spec_version": "prompt-spec-v1",
  "channel": "doubao-jimeng",
  "items": [
    {"slot": 1, "file": "cover_01_hit.png", "title_id": "T1",
     "composition": "爆点仰拍", "size": [2848, 1600], "prompt": "<五段全文>"},
    {"slot": "vertical", "file": "cover_04_vertical.png", "title_id": null,
     "composition": "胸像逆光", "size": [1080, 1920], "prompt": "<五段全文>"}
  ]
}
```

竖版默认用封面1 的标题取元素，`title_id` 可填来源横版；`prompts.md` 是同内容的整段复制版，供人工渠道直接粘贴。
