# 短剧标题生成 v3 规范

## 总则

- 繁體字、第三人稱「他」；禁用主角本名，不擅自增改劇情。
- 每版 ≤80 字；全程最誇張、最抓馬，鉤子和爽點盡量塞滿，能放大的爽點一律放大（現錢堆山、一車車拉回、賣爆全縣、全村仰望等）。
- 開頭優先埋強衝突鉤子，善用「誰知/誰料」製造意外轉折，異能用直白畫面表述，避免生硬系統術語。

## 版1｜爽文①·先抑後揚·抓馬現場打臉線

- 開頭踩慘劇/絕境鉤 → 重生/覺醒當場反擊 → 暴富/異能誇張展現 → 現場打臉反派 → 誇張幸福/成就結尾。
- 走即時狗血、當場羞辱路線，節奏快，開口就抓眼。

## 版2｜爽文②·先抑後揚·前世回溯雪恥線

- 前世/前史慘狀深度回溯 → 開掛翻盤 → 複仇/奪業打臉 → 「連本帶利討回一切/不讓悲劇重演」收尾。
- 與①拉開差異：①重現場即時打臉，②重積累回溯雪恥，不重複同一鏡頭。

## 版3｜傳奇版·專屬狠反問·兩套默認範式

- 核心原則：反問必須綁定本劇專屬劇情（背叛細節、核心能力、身份反差），禁用通用套話，每部不重複。
- 誅心戳背叛款：緊扣背叛/構陷細節，戳破對方「兄弟/情義」偽裝，直擊道德痛點。
- 霸氣守山款：以主角地位/地盤/實力為核心，踩對方「不配入門/分一杯羹」，凸顯地位碾壓。

## 禁止

- 平淡鋪陳、用第一人稱、生搬模板、出現主角本名、私加劇情、超過80字。
- 傳奇版反問使用無差別通用句式，必須結合劇情專屬定製。
